# Overseer Skill

AI skill for adding Codmir Overseer error tracking, 15-second DVR session replay, and AI-powered incident management to your application.

## Quick Start

Paste this prompt into your AI coding agent (Claude, Cursor, Copilot, etc.):

```
Install the Overseer AI skill from github.com/codmir-labs/skills and use it to add error tracking to this application with Overseer following best practices.
```

## What This Skill Does

When invoked, the AI agent will:

1. Install `@codmir/sdk` into your project
2. Set up error boundary and global error handlers
3. Configure session replay with 15-second DVR buffer
4. Add environment variables for your DSN and client key
5. Apply framework-specific best practices (Next.js, React, Vue, Express, etc.)

## Manual Setup

If you prefer manual setup, see the [Overseer documentation](https://codmir.com/docs/overseer).
